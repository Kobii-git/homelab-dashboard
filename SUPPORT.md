# Support

Use [GitHub issues](https://github.com/Kobii-git/homelab-dashboard/issues) for reproducible bugs,
documentation corrections and feature proposals. Search existing issues first. Support is voluntary;
there is no service-level commitment.

Include the app version/commit, operating system, browser, deployment method and a minimal example
with invented data. Remove cookies, authorization headers, passwords, API keys, email addresses,
private hostnames/IPs and identifying bookmark content from screenshots and logs. Never attach a
real database, `.env`, configuration ZIP or backup. Use [SECURITY.md](SECURITY.md) for vulnerabilities.

Read [CONTRIBUTING.md](CONTRIBUTING.md) for local development and testing, and the operator runbooks
in [README.md](README.md) for private HTTPS deployment and recovery.
