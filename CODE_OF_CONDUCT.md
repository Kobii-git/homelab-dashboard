# Community conduct

Be respectful, specific and constructive. Critique ideas and code without harassment, threats,
discrimination or personal attacks. Respect privacy; never publish someone's private information or
credentials. Assume good intent while remaining willing to correct mistakes.

Maintainers may edit or remove harmful contributions and restrict participation when necessary.
Use GitHub's private report-abuse controls for harassment or private-data disclosure. For project
moderation help, ask a maintainer for a private channel without posting sensitive details publicly.
This policy applies to the project's issues, reviews, discussions and other project spaces.
